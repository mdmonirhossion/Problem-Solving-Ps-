# STN-7 Problem Solving

This folder contains my solutions to the 20 problems in the STN-7 assessment. All solutions are in [solution.ts](./solution.ts), with each problem marked by a comment.

## Run the tests

Open PowerShell in this folder and run:

```powershell
npx tsx solution.test.ts
```

The test file checks the examples from the assignment and some extra cases. A successful run ends with a summary such as `76 passed, 0 failed`.

## A few details

- The functions use the names and parameters from the assignment.
- Problems 12, 14, 15, and 18 change the input array directly, as required.
- For Problem 20, Example 3, the longest common prefix is `"inters"`: all three words (`interspecies`, `interstellar`, and `interstate`) begin with those six letters.
